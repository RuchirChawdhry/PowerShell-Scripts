Make Windows do more.

Small, independent PowerShell commands for hardware, batteries, process lookup, QR codes, and pixel-perfect desktop screenshots. Built for Windows 11 and PowerShell 7+.

QUICK START

Dot-source any one script.

No module setup, shared helper files, or framework required.

. .\Get-QR.ps1
Get-QR 'Hello Windows' -Terminal -Window

. .\Get-HWInfo.ps1
(Get-HWInfo -Category CPU, RAM).CPU
REFERENCE

The commands

Everything documented, one file per utility.

DEVICES

Get-BluetoothBattery ↗

Read battery percentages reported by connected Bluetooth accessories.

 POWER

Get-BatteryInfo ↗

Inspect designed capacity, full-charge capacity, remaining charge, and health.

 GRAPHICS

Get-QR ↗

Turn UTF-8 text into a PNG, a terminal QR, and a window preview.

 WINDOWS

Get-HWND ↗

Find HWNDs by fuzzy process name, window title, or exact PID.

 PROCESSES

Get-ProcesID ↗

Locate process IDs with the same fuzzy search as HWND lookup.

 HARDWARE

Get-HWInfo ↗

Retrieve Windows hardware sections through CIM/WMI.

 CAPTURE

Get-Screenshot ↗

Capture an exact visible HWND rectangle as an opaque PNG.

 CAPTURE

Get-ScreenshotJumplist ↗

Open an app's real taskbar Jump List and capture the popup.
REQUIREMENTS

Lightweight by design.

  • Windows 11 and PowerShell 7+ for all commands.
  • Get-QR is pure PowerShell/.NET; it needs no PowerShell Gallery modules.
  • Screenshots use Microsoft WinApp CLI, installable with winget install Microsoft.winappcli --source winget, on an unlocked interactive desktop.
  • Battery and hardware queries rely on Windows-provided properties and WMI/CIM.
